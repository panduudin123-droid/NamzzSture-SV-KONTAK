# NAMZZ Save Kontak

Aplikasi Android untuk mengimpor dan menyimpan kontak ke perangkat secara otomatis menggunakan file CSV.

## Fitur
- Import file CSV dengan format `name,phone`.
- Menyimpan kontak langsung ke buku telepon perangkat dengan izin yang aman.
- Antarmuka berbasis tema gelap yang modern.

## Cara Penggunaan
1. Unduh dan pasang aplikasi.
2. Siapkan file CSV dengan format nama dan nomor telepon.
3. Pilih file melalui aplikasi, lalu klik tombol simpan.
